# IoC 컨테이너


: Inversion of Control
- 객체 생성, 생명주기 관리, 의존성 주입을 스프링이 대신하는 구조
  - 핵심 역할: Bean 등록, 관리, 주입
- Bean(객체)을 생성/관리하며, 필요 시 주입해주는 역할 = ApplicationContext
---
## DI


: Dependency Injection
- 객체가 필요한 의존성을 스스로 만들지 않고, 외부로부터 주입받는 것 

| 구분     | 특징                                | 주입 방식                                                |
|--------|-----------------------------------|------------------------------------------------------|
| 생성자 주입 | 불변성 유지, 필수 의존겅 보장, 테스트 용이         | 생성자 파라미터로 의존성 주입 <br/> 필수 의존성 주입에 적합 <br/> 객체 불변성 유지 |
| 세터 주입  | 선택적 의존성 주입 가능, 변경 가능성 O           | setter 메서드를 통해 주입 <br/> 선택적 의존성 주입에 유용               |
| 필드 주입  | 가장 간단하지만 테스트 어려움, 스프링 컨테이너에 강한 결합 | `@Autowired` <br/> 필드에 직접 주입                         |
---
## AOP


: Aspect-Oriented Programming
- 관심사의 분리를 위해 핵심 로직과 부가 기능(로깅, 트랜잭션 등)을 분리하는 기술

| 개념    | 설명                                |
|-------|-----------------------------------|
| 포인트컷  | 부가기능이 적용될 지점(메서드 등)을 지정하는 표현식     |
| 조인포인트 | 실제 실행 가능한 모든 지점(메서드 호출, 생성자 호출 등) |
| 어드바이스 | 적용할 부가기능 자체(로깅, 트랜잭션 등)           |
| 위빙    | 포인트컷에 따라 실제 실행 시 어드바이스를 삽입하는 과정   |

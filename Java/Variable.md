## Variable


: 유동적 변경 발생 값
- 컴퓨터 메모리의 데이터 저장소

#### 변수명 작성 규칙
- 대/소문자 구분 + 공백 불가
- 숫자로 시작 불가
- 특수문자의 경우 $, _만 가능
- Java 예약어(키워드) 불가
- 의미를 담아 작성(관례적)
- camelCase 표기
---
#### 지역변수
- 메서드/블록 내부에서 선언
- 해당 범위 내에서만 O
- 초기화 X = 사용 X
#### 멤버변수
- 클래스 내부 선언
- 객체 생성 시, 메모리에 할당
- 초기화 X = 자료형 기본 값 자동 초기화
#### 클래스변수
- static 키워드 사용 선언
- 모든 객체가 공유
- 클래스 로드 시, 메모리 1번만 생성
---
### 변수 선언 및 초기화
- 변수의 선언: 자료형 + 이름;
- 변수의 초기화
  - 변수에 값 저장
  - 선언과 동시에 초기화

```java
int a;
double b;

a = 10;
b = 10.0;

int f = 1000;
```

## Data Type
*1byte = 8bit
- 기본 자료형: 변수 자체에 값을 직접 저장

  | 자료형     | 크기     | 기본값     |
  |---------|--------|---------|
  | boolean | -      | false   |
  | char    | 2byte  | null 문자 |
  | byte    | 1byte  | 0       |
  | short   | 2byte  | 0       |
  | int     | 4byte  | 0       |
  | long    | 8byte  | 0L      |
  | float   | 4byte  | 0.0f    |
  | double  | 8byte  | 0.0d    |
- 참조 자료형: 변수에 참조(레퍼런스, 주소) 저장, 기본값: null
  - e.g.) String, Array, Map, Set, ...

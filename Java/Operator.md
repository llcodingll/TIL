## Operator


: 계산/처리 수행 기호

---
## Operand


: 연산의 대상이 되는 값/변수

---
### 연산자 우선순위
괄호 - 단항 - 산술 - 비교 - 논리 - 대입

---

### 산술 연산자
- 정수, 정수 연산 = 정수
- 정수, 실수 연산 = 실수
```java
+, -, *, /, %
```
---
### 비교 연산자
- 두 값을 비교해 참/거짓 반환
- 문자열 비교는 `.equals()` 활용
```java
==, !=, >, <, >=, <=, instanceof
```
---
### 논리 연산자
- 조건을 조합해 참/거짓 반환
- 단락평가(단축평가): 앞의 조건을 보고 뒤를 확인해 할 지 말 지를 결정
  - 결과를 더 확인할 필요가 없는 경우, 남은 조건을 연산하지 않고 통과
```java
&&, ||, !
```
---
### 대입(복합) 연산자
- 변수에 값을 할당
- 산술 + 대입 축약 사용
```java
=, +=, -=, *=, /=, %=
```
---
### 단항 연산자
- 하나의 피연산자에만 작용
- 변수 값이 상태를 변경/체크 시 사용
```java
+, - : 부호 변경
++a, --a : 전치 연산
a++, a-- : 후치 연산
! : 논리 NOT 연산
~ : 비트 NOT 연산
(type)a : 형 변환
```
---
### 기타 연산자
- 삼항 연산자, new 연산자, [인덱스] 배열 접근자, .(객체 멤버 접근)연산자, 비트연산자, ...

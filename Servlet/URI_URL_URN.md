## URI
- 통합 자원 식별자
- 인터넷 상 `자원의 고유한 식별`
- URL과 URN을 포함하는 상위 개념

## URL
- `자원 위치` 제공
### 구성 요소
- 프로토콜 : 절차를 포함한 통신 규약
  - http:, https:
- 서버 : 웹 페이지를 요청할 서버 주소, 실제 IP 주소나 도메인 입력 가능
  - www.~~.com
- 경로 : 서버 내의 상세 경로
  - register, ...
- Query String : 추가로 서버로 데이터를 전송하기 위해 사용하는 부분
- `?` 마크를 적어 시작 표시
- Parameter Name = value 형태로 작성, 파라미터 여러 개일 경우, `&`로 구분해 작성
  - ?id=123
## URN
- `자원의 고유한 이름` 제공

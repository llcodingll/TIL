## Cognito
: 웹/앱에 대한 인증, 권한 부여, 사용자 관리 등등 로그인 관련 서비스

### 내부 로직
#### 사용자풀(User pool)
    - 사용자의 로그인 request
    - 인증을 위한 추가적인 조건을 중족하도록 함
    - 해당 조건을 충족하면 인증된 토큰으로 로그인하게 해달라고 app에 request
    - app에서는 인증/인가된 토큰과 data를 api database에 넘기면서 로그인 됨

#### Id풀(ID pool)
    - 사용자와 app이 붙어있는 것
    - 인증과 토큰 request와 인가(선택)가 같이 자격 증명이나 user pool로 들어감
    - 아니면 개발 인증, 토큰, 인가된 거가 cognito의 identity pool에 request 들어감
    - 거기서 request 역할 부여
    - 그게 되면 이 역할에 자격을 부여해 반환

### Past-Forward 프로젝트에서 활용한 이유
1. SNS 로그인을 사용하기로 기획단에서 결정이 났고, 이를 백엔드 서버를 한 번 더 거치는 과정을 줄이고 로그인하기 위해 Cognito를 인프라팀에서 구축해보기로 함.

2. 프리티어를 사용할 예정이었기 때문에 프리티어 지원해주는지 확인해야 했음. 당시 Cognito도 지원해주었고 사용자 인증과 고유 식별자 생성을 위한 ID풀 사용이 무료였어서 결정.
